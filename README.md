# stardroid

Android client for the Star project ( Blindsoft / G4P Studios ).

Imported from the `star android` workspace. Source only — build artifacts
( `android_tools.zip`, `gradle.zip`, `node_modules/`, `.gradle/`, `android_sdk/` )
are gitignored.

## Build
Standard Gradle/Android build. See `app/` and the gradle files.
